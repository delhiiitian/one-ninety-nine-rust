# Why learn Rust?

Rust gives you **speed** like C and *safety* like a modern language.
It is used by [Discord](https://discord.com), Cloudflare and Microsoft.

## Three reasons

1. No crashes from null values
2. Fearless concurrency
3. A friendly compiler

## Quick taste

```rust
fn main() {
    let names = vec!["Asha", "Dev"];
    for n in &names {
        println!("Hello, {n}!");
    }
}
```

> The compiler is your pair programmer.
